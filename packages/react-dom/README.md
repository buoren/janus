# @janus/react-dom

React DOM (web) form components for decision-tree registration forms — the web sibling of [`@janus/react-native`](https://www.npmjs.com/package/@janus/react-native), built on [`@janus/react-core`](https://www.npmjs.com/package/@janus/react-core).

## Install

```bash
npm install @janus/react-dom
```

Requires `@janus/core`, `@janus/react-core`, and `react` (>=18) as peer dependencies.

## Exports

- **Components**: `FormPage`, `TotalBar`, `QuestionRenderer`
- **Styles**: `createFormStyles(theme)` — pass `{ primaryDark, textPrimary }` to get a full form stylesheet
- **Hooks & types**: re-exported from `@janus/react-core`

Part of the [Janus](https://github.com/buoren/janus) monorepo.
